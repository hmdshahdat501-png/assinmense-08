# 📚 BookLence - Online Book Shop

Live Site: https://assinmense-08.vercel.app/

## 🚀 Project Overview

BookLence is a modern online book shop built with Next.js. Users can browse books, view details, and explore different categories like Story, Tech, and Science.

---

## ✨ Features

- 📖 Browse all books
- 🔍 Search functionality
- 📂 Category filtering (Story, Tech, Science)
- 📄 Single Book Details Page
- ⚡ Fast performance with Next.js
- 🌐 Deployed on Vercel

---

## 🛠️ Technologies Used

- Next.js
- React
- Tailwind CSS
- JSON (for data)
- Vercel (Deployment)
